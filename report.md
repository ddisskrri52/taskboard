Лабораторна 2
1. Що змінилося у виводі git status після git add ?
Файли стали зеленими і перейшли в індекс (Staging Area). Це означає, що Git підготував їх до збереження і вони чекають на коміт.
2. Що показує git diff ?
Він показує різницю між тим, що я накодив у файлах зараз, і тим, що було збережено раніше. Нові рядки підсвічуються зеленим із плюсом, а видалені — червоним із мінусом.
3. Чим відрізняється git switch main від git merge ?
git switch main — це просто перехід на гілку main, щоб працювати в ній. A git merge — це злиття, коли я беру зміни з іншої гілки і додаю їх у поточну.
4. Чому виник конфлікт і як ти його розв'язав?
Конфлікт стався, бо я змінила один і той самий рядок у index.html і в гілці main, і в гілці ukr-title. Git не зрозумів, який варіант залишити. Я відкрила файл, видалила усі ці стрілочки, написала один нормальний заголовок, зробила git add і закомітила.
